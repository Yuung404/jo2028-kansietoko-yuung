Administrateur (Tests\Fonctionnel\Administrateur)

  • Ajouter un administrateur enregistre une empreinte Bcrypt
  • Un administrateur ne peut pas supprimer son propre compte

Authentification (Tests\Fonctionnel\Authentification)

  • Les pages d'administration sont inaccessibles sans connexion
  • Un administrateur peut se connecter
  • Un mauvais mot de passe est refusé avec un message générique
  • La déconnexion ferme l'accès au back-office

Securite (Tests\Unitaire\Securite)

  • L'échappement HTML neutralise une balise script (XSS)
  • Le jeton CSRF est aléatoire (64 caractères) et stable pendant la session
  • Une requête sans jeton CSRF est refusée
  • Une requête avec un faux jeton CSRF est refusée
  • Une requête avec le bon jeton CSRF est acceptée
  • Bcrypt produit une empreinte salée et vérifiable
  • Les empreintes du jeu d'essai correspondent aux mots de passe de l'annexe 2

Sport (Tests\Fonctionnel\Sport)

  • Ajouter un sport
  • Un sport en double est refusé (majuscules et espaces ignorés)
  • Modifier un sport
  • La modification vers un nom déjà utilisé est refusée
  • Supprimer un sport
  • Un sport utilisé par une épreuve ne peut pas être supprimé
  • Une suppression sans jeton CSRF ou par simple lien est refusée
  • Un nom de sport malveillant est affiché sans être exécuté (XSS)

Validation (Tests\Unitaire\Validation)

  • Un texte obligatoire vide est refusé
  • Un texte trop long est refusé
  • Un texte valide est accepté (y compris 255 caractères accentués)
  • La longueur compte les caractères et non les octets
  • Les dates impossibles sont refusées (31 février, 29 février hors année bissextile)
  • Les heures invalides sont refusées
  • Le format du login est contrôlé
  • Les règles du mot de passe sont appliquées (8 caractères min., 72 octets max., confirmation)
